Cấu hình Google Database API

Đồng bộ dữ liệu chung giữa mọi thiết bị:

1. Mở Google Apps Script → Tạo Database Web App.

2. Triển khai dưới dạng Web App với quyền truy cập là Bất kỳ ai (Anyone).

3. Dán đường dẫn Web App kết thúc bằng /exec vào ô bên dưới.
